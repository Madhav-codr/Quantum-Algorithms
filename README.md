# Quantum Algorithms: Self-paced course  

## Goal  

The aim of this course is to provide a guided journey to beginners in Quantum Algorithms.  

## Prerequisites  

Basic understanding of linear algebra, quantum gates and quantum circuits.  

## Why this course?  

This course aims to bring mathematics, qiskit implementation and applications/projects based on algorithms for applied quantum computing. Every step of algorithm analysis is clearly stated so that someone who is not from real-analysis background of mathematics can also clearly understand it.
